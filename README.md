  <img align="right" width="48%" src="https://github-readme-stats.vercel.app/api/pin/?username=xiaoyuyu6420&repo=dsh-backup&theme=tokyonight&show_owner=true" alt="dsh-backup"/>

**[dsh-backup](https://github.com/xiaoyuyu6420/dsh-backup)** — DeepSeek Harness (DSH) 的备份插件，一条命令备份/恢复整个 `~/.dsh`：

- ⚡ 升级前自动快照，宿主起不来也有零依赖救援通道
- 🩺 会话日志体检 `/backup doctor`，日志坏了能修
- 🔒 凭据默认脱敏不出本机

从 0.1 迭代到 0.9，多个修复来自社区 issue 的根因分析 · [反馈直达](https://github.com/xiaoyuyu6420/dsh-backup/discussions/32)
